# Module 04 — CRUD operations

**Goal:** create, read, update, and delete records with JDBC.

## Concepts

- Use `executeQuery()` for queries that return a `ResultSet`.
- Use `executeUpdate()` for INSERT, UPDATE, and DELETE.
- Check affected-row counts.
- Use `PreparedStatement` for runtime values.
