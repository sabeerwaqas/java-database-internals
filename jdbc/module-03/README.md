# Module 03 — ResultSet and Java type mapping

**Goal:** read query results and map SQL values to appropriate Java types.

## Concepts

- A `ResultSet` cursor starts before the first row; call `next()` to advance.
- Read columns by label or index.
- Use `BigDecimal` for SQL `DECIMAL` values such as money.
- Use Java time types for date and timestamp columns.
