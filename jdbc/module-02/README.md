# Module 02 — Statement and PreparedStatement

**Goal:** execute SQL and understand parameter binding.

## Concepts

- `Statement` executes SQL text.
- `PreparedStatement` represents SQL with placeholders.
- Bind values with typed setter methods such as `setLong`, `setString`, and `setBigDecimal`.
- Avoid concatenating user-provided values into SQL.
